# GarageMaster

GarageMaster — веб-сервис для поиска частных автомастерских и гаражных мастеров. Пользователь может найти гараж, посмотреть услуги, рейтинг, отзывы, выбрать свободное время и оставить заявку. Мастер управляет карточкой гаража, расписанием, заявками и отзывами. Администратор модерирует карточки, видит статистику, заявки, пользователей, отзывы и обращения в поддержку.

## Роли и демо-аккаунты

- Администратор: `admin@example.com` / `admin123`
- Мастер: `master@example.com` / `master123`
- Пользователь: `user@example.com` / `user123`

## Что есть в проекте

- каталог гаражей с фильтрами по услуге, району, рейтингу и свободному времени;
- карточка гаража с фото, картой, услугами, ценами, отзывами и онлайн-записью;
- занятые и свободные слоты отображаются разными цветами;
- профиль пользователя с аватаркой, описанием, автомобилем, заявками и отзывами;
- кабинет мастера с заявками, историей, карточками гаражей, расписанием, отзывами и профилем мастера;
- жизненный цикл заявки: новая, подтверждена, в работе, выполнена, отменена;
- отзывы доступны только после выполненной заявки;
- мастер может ответить на отзыв;
- избранное сохраняется в базе для авторизованных пользователей;
- поддержка: пользователь/мастер создаёт обращение, администратор отвечает;
- админка со статистикой, модерацией, пользователями, заявками, отзывами и поддержкой;
- мобильное нижнее меню и адаптивная вёрстка;
- PostgreSQL для Render.

## Локальный запуск

Нужен Node.js 22+ и PostgreSQL.

1. Создайте файл `.env` в корне проекта.
2. Заполните его по примеру `.env.example`.
3. Выполните команды:

```bash
npm install --include=dev --registry=https://registry.npmjs.org/
npm run dev
```

Фронт будет доступен на `http://127.0.0.1:5173`, API — на `http://127.0.0.1:3000`.

## Деплой на Render

Создайте PostgreSQL базу на Render, скопируйте Internal Database URL и добавьте переменные окружения в Web Service:

```text
NODE_VERSION=22.14.0
HOST=0.0.0.0
JWT_SECRET=garage_master_super_secret_2026
DATABASE_URL=Internal Database URL от Render Postgres
GEOCODE_DEFAULT_CITY=Ульяновск, Россия
GEOCODE_USER_AGENT=GarageMaster/1.0
```

Build Command:

```bash
rm -f package-lock.json && npm install --include=dev --registry=https://registry.npmjs.org/ && npm run build
```

Start Command:

```bash
npm start
```

После изменения файлов на GitHub выполните в Render: `Manual Deploy → Deploy latest commit`.
