# GarageMaster

GarageMaster — учебный веб-сайт агрегатора частных автомастерских и гаражных мастеров в городе Ульяновск.

Проект включает React/Vite фронтенд, Fastify API, PostgreSQL, авторизацию, роли пользователей, каталог мастерских, избранное, онлайн-заявки, кабинет мастера, админ-панель модерации, реальные отзывы и уведомления.

## Запуск локально

Для локального запуска нужен PostgreSQL.

1. Создай базу PostgreSQL, например `garage_master`.
2. В корне проекта создай файл `.env` или задай переменные окружения:

```text
DATABASE_URL=postgresql://USER:PASSWORD@localhost:5432/garage_master
JWT_SECRET=dev-secret-change-me
HOST=0.0.0.0
GEOCODE_DEFAULT_CITY=Ульяновск, Россия
GEOCODE_USER_AGENT=GarageMaster/1.0
```

3. Установи зависимости и запусти проект:

```bash
npm install
npm run dev
```

Открыть сайт:

```text
http://127.0.0.1:5173
```

API запускается на порту 3000.

## Сборка

```bash
npm run build
npm start
```

После сборки React-фронтенд копируется в `apps/api/public`, а Fastify отдаёт и API, и готовый сайт.

## Основные возможности

- каталог частных автомастерских;
- поиск по услугам, названию, району и описанию;
- фильтры по району, рейтингу, цене и видам работ;
- карточка гаража с фото, описанием, услугами, ценами, отзывами и картой;
- карта оставлена внутри полной карточки гаража, а не на странице каталога;
- кнопка построения маршрута через Яндекс.Карты;
- лента работ мастеров с фото до/после;
- избранные гаражи;
- онлайн-заявка на ремонт по свободному слоту;
- личный кабинет клиента с заявками, уведомлениями и формой отзыва после завершённой работы;
- реальные отзывы из базы данных, привязанные к выполненным заявкам;
- автоматический пересчёт рейтинга мастера после отзыва;
- кабинет мастера с созданием гаража, услугами, ценами, расписанием и загрузкой фото через форму;
- редактирование расписания и генерация новых свободных слотов;
- автоматическое получение координат гаража по адресу;
- админ-панель с модерацией карточек, причиной отказа и уведомлением мастеру;
- нижнее мобильное меню для удобной навигации на телефоне;
- улучшенная шапка с аккуратными кнопками и индикатором уведомлений.

## Деплой на Render

Проект подготовлен как один Node.js Web Service. Для базы используется Render Postgres.

Рекомендуемые настройки Web Service:

```text
Runtime: Node
Build Command: npm install && npm run build
Start Command: npm start
Environment variables:
  NODE_VERSION=22.14.0
  HOST=0.0.0.0
  JWT_SECRET=<любой длинный секрет>
  DATABASE_URL=<Internal Database URL из Render Postgres>
  GEOCODE_DEFAULT_CITY=Ульяновск, Россия
  GEOCODE_USER_AGENT=GarageMaster/1.0
```

В репозитории есть `render.yaml`. Через Blueprint Render может создать Web Service и PostgreSQL-базу автоматически. Если создаёшь вручную, сначала создай Postgres, потом вставь его Internal Database URL в переменную `DATABASE_URL` у Web Service.

Сервер использует `process.env.PORT`, который Render выдаёт автоматически, и слушает `0.0.0.0`.

## Примечание по фото

Фото в учебной версии сохраняются как data URL. Для реального коммерческого запуска лучше вынести изображения в S3, Cloudinary, Supabase Storage или другое файловое хранилище.
